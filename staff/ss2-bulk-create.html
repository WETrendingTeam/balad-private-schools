SS2 Student Bulk Creation

This one-time tool uses your currently signed-in Class Teacher session. It creates only students that are not already present in your SS2 class. It does not upload photos.

Department: the notebook does not state each student's department, so this tool sends Department as blank. If the Worker requires a department, those students will be reported as failed rather than guessed.
